### The Four Modes of Content

1. **Encyclopedic reference** — data-driven, "look it up" (Cooking, Music, Flags, Periodic)
2. **Living simulation** — model real processes, watch them unfold (Automata, Cell, Fluid, Neurons)
3. **Mechanical beauty** — engineering as art, gears and pistons (Mechanics)
4. **Pure ambiance** — no information, just presence (Plasma, Aurora, Fire, Lake)

The strongest axis is the **scale-of-the-universe journey**: Quarks → Molecule → DNA → Cell → Microscope → Earth → Orbits → Constellations. Mechanics covers a **timeline of invention**: Antikythera → Gutenberg → Beam Engine → Locomotive → Curta. Cooking is becoming a **culinary school**: foundations → technique → regional → global.

## BLIND SPOTS (missing categories)

### 1. MATHEMATICS — the biggest gap

Zero dedicated math visuals despite deep science coverage. Math is inherently beautiful on LED — pure pattern, minimal text.

**Potential visuals:**

| Visual | Type | Description |
|--------|------|-------------|
| **Spirals** | Simulation | Ulam spiral (prime distribution), Fibonacci/golden spiral, Archimedean spiral |
| **Tessellations** | Simulation | Penrose tiling, Islamic geometric patterns, Escher-style, Voronoi |
| **Pi** | Reference | Digit stream, circle-polygon convergence, Monte Carlo estimation |
| **Curves** | Simulation | Spirograph/epicycloids, Lissajous figures, harmonograph, involutes |
| **Primes** | Simulation | Sieve of Eratosthenes animation, prime counting staircase |
| **Polyhedra** | Simulation | Rotating wireframe platonic solids (tetra, cube, octa, dodeca, icosa) |
| **Chaos** | Simulation | Logistic map bifurcation, Mandelbrot zoom (complement Fractals) |
| **Topology** | Simulation | Klein bottle, torus, trefoil knot — wireframe morphing |
| **Pascal** | Simulation | Pascal's triangle with mod-coloring (Sierpinski emerges) |
| **Cellular** | Simulation | Langton's ant, turmites (distinct from existing CA) |

**Why it matters:** Math is the bridge between Science and Art. Many existing visuals are *implicitly* mathematical (Fractals, Attractors, Turing patterns) but nothing teaches math explicitly.

### 2. LANGUAGE & WRITING — completely absent

The machines that produce text exist (Typewriter, Gutenberg) but the content they produce is missing.
